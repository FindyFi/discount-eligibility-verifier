Credential verifier

Checks pensioner and student credentials from EUDI-compatible wallets, with issuers trusted through OpenID Federation.

Open the kiosk page. The integration API is described in the project README.

Live demo

This demo starts sessions from the kiosk endpoint, so it works only when kiosk.enabled is set. Your own page would start sessions from your backend instead.

Embed it

  
Your backend creates the session with its API key, then hands the session id and browser token to the page:

  
<script type="module" src="https://verifier.example.com/verifier.js"></script>

<credential-verifier
    session-id="…" session-token="…"
    lang="fi" sound="on" page-feedback="off">
</credential-verifier>

<script>
  document.querySelector('credential-verifier')
    .addEventListener('verification-result', (e) => {
      // Show feedback. Grant the discount only from the result your backend receives
      // (webhook or GET /api/sessions/{id}), never from this browser event alone.
      console.log(e.detail.outcome, e.detail.credentialType);
    });
</script>

  
Alternatively, set start-url to an endpoint of your backend that creates a session and returns { "session_id", "browser_token" }.
